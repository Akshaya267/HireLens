# Screenshots

This folder is where UI screenshots for the submission/demo go.

Suggested shots to capture after running `python3 server.py` and
opening `http://localhost:8000`:

1. `01-dashboard.png` — Home/Dashboard view with stats and pipeline strip
2. `02-jd-input.png` — Job Description input screen
3. `03-resume-upload.png` — Resume upload screen with sample resumes loaded
4. `04-analyze.png` — Analyze screen showing the C engine's console output
5. `05-ranking.png` — Candidate ranking table
6. `06-candidate-detail.png` — Individual candidate breakdown (score
   meters, matched/missing skills, strengths/gaps, recommendation)
7. `07-export.png` — Export screen

These are intentionally not pre-generated since they depend on the
live UI rendering in your browser — capture them locally before your
submission/demo and reference them from the README if desired, e.g.:

```md
![Dashboard](screenshots/01-dashboard.png)
```
